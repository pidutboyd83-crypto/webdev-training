# webdev-training

A simple web development training project with example pages and basic HTML structure.

## Project files

- `index.html` — main homepage template.
- `contacts.html` — contact page layout.

## Usage

1. Open `index.html` in a browser to view the homepage.
2. Open `contacts.html` in a browser to view the contact page.

## Notes

- This repository is intended for learning and practicing basic HTML structure.
- Add styles, assets, and scripts as needed to expand the project.
